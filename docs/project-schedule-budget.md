## 7. Potential Schedule Delays

Three tasks may significantly affect the project schedule:

1. **T05 – Design Initial Wireframes:** Delays may affect the development of both the student request interface and admin dashboard.
2. **T07 and T08 – Interface and Dashboard Development:** Delays in either task may postpone testing and prototype completion.
3. **T09 – Develop and Execute Test Cases:** Delays may affect the final project review and submission.

The team will monitor these tasks closely and communicate any delays through GitHub Issues.

## 8. Conclusion

The CampusHelp project is planned to be completed within 10 working days. The schedule defines four milestones, twelve tasks, task dependencies, and resource responsibilities.

The estimated total project budget is 2,250,000 UZS based on 45 estimated person-hours. Regular progress monitoring and communication will help the team complete the project within the planned schedule.
