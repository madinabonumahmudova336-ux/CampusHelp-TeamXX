CampusHelp – Business Analysis
1. Business Requirements
- Students must be able to submit service requests online.
- Students should be able to select request categories and priorities.
- Administrators must be able to manage and track submitted requests.
- Students should receive confirmation after submitting a request.

2. Functional Requirements
- The system allows students to submit requests.
- The system provides category and priority selection.
- The system displays request status.
- Administrators can view and manage requests.
- The system provides submission confirmation.

3. Non-Functional Requirements
- The interface should be easy to use.
- The system should provide reliable access.
- Student information should be protected.
- The system should respond within a reasonable time.

4. Student Needs
- Easy request submission.
- Clear request categories.
- Ability to select priority.
- Confirmation after submission.
- Ability to track request status.

5. Administrator Needs
- Access to submitted requests.
- Ability to review and manage requests.
- Request status visibility.
- Organized request information.

6. Expected System Outcomes
CampusHelp is expected to improve communication between students and university administration, simplify service request management, and provide better request tracking.
