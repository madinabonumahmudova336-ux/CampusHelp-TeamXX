# CampusHelp – Stakeholder Requirements

## 1. Stakeholders
- University students
- University administration
- Student support staff

## 2. Student Requirements
- Submit service requests online.
- Select a request category.
- Set request priority.
- Receive confirmation after submission.
- View request status.

## 3. Administrator Requirements
- View submitted requests.
- Track request status.
- Review request categories and priorities.
- Manage and respond to requests.

## 4. System Requirements
- Simple and user-friendly interface.
- Required fields must be completed.
- Requests must be stored and organized.
- Confirmation must appear after submission.

## 5. Expected Outcome
A centralized portal that improves communication between students and university administration.
