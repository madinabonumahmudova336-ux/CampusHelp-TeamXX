# CampusHelp – Administrator Dashboard

## 1. Overview

The Administrator Dashboard is designed to help university administrators manage student service requests in one place.

## 2. Dashboard Summary

The dashboard displays the following information:

- Total Requests
- Open Requests
- In Progress Requests
- Completed Requests

## 3. Request Management Table

| Request ID | Student | Category | Priority | Status |
|---|---|---|---|---|
| REQ-001 | Student A | IT Support | High | Open |
| REQ-002 | Student B | Library Assistance | Medium | In Progress |
| REQ-003 | Student C | Classroom Maintenance | Low | Completed |

## 4. Administrator Functions

Administrators can:

- View all submitted student requests.
- Review request descriptions.
- Assign requests to relevant departments.
- Change request status.
- Monitor request progress.
- Identify high-priority requests.

## 5. Request Status

The dashboard uses three main statuses:

- Open
- In Progress
- Completed

## 6. Design Description

The dashboard includes:

- A navigation sidebar.
- Summary cards showing request statistics.
- A request management table.
- Priority indicators.
- Status indicators.
- Request management actions.

## 7. Prototype Limitations

This dashboard represents a proposed prototype. Request data, department assignment, and status updates are simulated and are not connected to a live university database.

## 8. Conclusion

The Administrator Dashboard provides a clear overview of student service requests and supports efficient request monitoring and management.
